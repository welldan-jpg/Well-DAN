# まるつけ帳（一問一答の丸つけ・集計）

`index.html` をブラウザで開くだけで使えます（サーバー・インストール・費用は不要）。

## できること
1. **正答表** … 別解は `|` 区切り（例 `4|四`）。JSON で書き出して校内共有すれば採点基準が統一できる。
2. **丸つけ** … 出席番号ごとに「全部○ → 間違いだけ×」、または答えを入力して自動判定。
   任意で写真を Gemini API に送り、答えを書き起こさせることもできる（既定オフ）。
3. **集計・指導ヒント** … 問題別正答率、よくある誤答、観点タグ別のつまずき、個別に声かけが必要な子。
   すべて端末内で計算。CSV（UTF-8 BOM）で書き出し → Excel / スプレッドシート / 校務システムへ取り込み。

## 個人情報の扱い
- 氏名は扱わず、出席番号のみ。
- 丸つけ結果はメモリ上だけ（閉じると消える）。保存は CSV を学校指定の場所へ。
- AI 読み取り時：氏名欄を塗りつぶし、画像を再エンコードして撮影情報（位置情報など）を除去。
  正答は AI に渡さない（正答に寄せて誤読するのを防ぐ）。○×はアプリが判定し、自信のない読み取りは要確認。
- **Gemini API の無料枠は、送信内容が Google の製品改善に使われ人がレビューし得る**。
  子どもの答案を送る場合は、所属のセキュリティポリシーの確認と、有料枠（Vertex AI 等）や
  学校契約の Google Workspace for Education 版 Gemini の利用を推奨。

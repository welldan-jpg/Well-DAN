# まるつけ帳（一問一答の丸つけ・集計）

`index.html` をブラウザで開くだけで使えます（サーバー・インストール・費用は不要）。

## 流れ
1. **① 正答表** … 別解は `|` 区切り（例 `4|四`）、配点・観点タグ・評価A/Bの目安（得点率）。
   JSON で書き出して校内共有すれば採点基準が統一できる。
2. **② 写真を取り込む** … Google Classroom の提出写真（ドライブの `Classroom/クラス名/課題名`）をまとめて選び、
   出席番号を割り当てる。
   - AIを使わない：写真だけ割り当て、③で写真を見ながら手で丸つけ（外部送信なし）。
   - AIを使う（任意・既定オフ）：共通の氏名マスクを掛けて Gemini API で一括書き起こし。答案の出席番号も読ませて割り当てと照合できる。
3. **③ 確認・丸つけ** … 写真と読み取り結果を横に並べて確認。自信のない読み取りは「要確認」で○×未記入。
   先生が「確認して保存」したものだけが集計に入る。
4. **④ 集計・評価確定** … 問題別正答率、よくある誤答、観点別のつまずき、評価 A/B/C、指導ヒント（すべて端末内で計算）。
   「評価を確定する」で書き換え不可にし、CSV（UTF-8 BOM）に確定日時を付けて書き出す。

## 個人情報の扱い
- 氏名は扱わず、出席番号のみ。
- 写真・丸つけ結果はメモリ上だけ（閉じると消える）。保存は CSV を学校指定の場所へ。
- AI 読み取り時：氏名欄を塗りつぶし、画像を再エンコードして撮影情報（位置情報など）を除去。
  正答は AI に渡さない（正答に寄せて誤読するのを防ぐ）。○×はアプリが判定する。
- **Gemini API の無料枠は、送信内容が Google の製品改善に使われ人がレビューし得る**。
  Classroom の写真を送ると学校の Workspace 契約の外に出るため、所属のセキュリティポリシーの確認と、
  有料枠（Vertex AI 等）や学校契約の Google Workspace for Education 版 Gemini の利用を推奨。

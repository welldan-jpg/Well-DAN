正答表（採点基準）をつくる

一問一答なら「採点基準」＝正答表です。別解は | で区切ります（例：4|四）。正答表は書き出して校内で共有すると、先生ごとの採点のブレを防げます。

観点タグの例：「送り仮名」「くり上がり」「同音異字」。集計で、どの観点でつまずいているかが分かります。正答表は個人情報を含まないので、この端末のブラウザに保存されます。

写真をまとめて取り込む

Google Classroom で集めた答案の写真をまとめて選び、出席番号に割り当てます。AIで一括読み取りすると、③で写真と読み取り結果を並べて確認できます。AIを使わず、写真を見ながら手で丸つけすることもできます。

写真をまとめて選ぶ

Classroom の提出物は、Googleドライブの マイドライブ / Classroom / （クラス名） / （課題名） にあります。選ぶ画面で Ctrl+A（Mac は ⌘+A）を押すと全部選べます。写真はこの画面の中だけで扱い、端末やブラウザには保存しません。

出席番号を割り当てる

Classroom はふつう名前順に並ぶので、番号は必ず確かめてください。答案に出席番号の欄があれば、AIに番号も読ませることができます（読んだ番号が割り当てと違うときは③で警告します）。

AIで一括読み取りする場合（任意）

送信前に必ず確認：写真は Google の Gemini API に送られます。無料枠では、送った内容が Google のサービス改善に使われ、人が閲覧する可能性があります。 Classroom の写真は学校の Google Workspace の中にありますが、ここで送ると学校の契約の外に出ます。学校・教育委員会の情報セキュリティポリシーで認められている場合だけ使ってください。

氏名欄の塗りつぶし（全部の写真に共通）

下の写真の上をドラッグして、氏名の位置を黒く塗ります。同じ位置がすべての写真に適用されます（撮影情報・位置情報も自動で消えます）。写真ごとに位置がずれる場合は、氏名を書く欄のない用紙（出席番号だけ）にするのが確実です。一覧の写真を押すと、その写真で位置を確かめられます。

無料枠は1分あたりの回数に上限があるため、1枚ずつ間をあけて送ります。AIには正答を渡さず「書いてある通りに書き起こす」だけを頼み、○×はこのアプリが正答表と照合して判定します（AIが誤字を正しい字に“補正”して読むのを防ぐため）。

    安全な使い方

    1回の流れ

    1. ① 正答表：宿題を出したら正答と評価の目安を入れる（学年で共有すると採点がそろう）。
    2. ② 写真を取り込む：Classroom の写真をまとめて選び、出席番号を割り当てる。AIで一括読み取り（許可がある場合のみ）か、写真だけ割り当て。
    3. ③ 確認・丸つけ：写真と結果を見比べ、黄色の「要確認」を直して「確認して保存」。全員ぶんくり返す。
    4. ④ 集計・評価確定：ヒントを見て、「評価を確定する」。CSV を書き出して学校指定の場所へ保存。

    このアプリの設計方針

    • 子どもは出席番号だけで扱い、氏名は入力しません。
    • 写真と丸つけ結果はブラウザのメモリ上だけにあり、ページを閉じると消えます。保存は先生がCSVを書き出して、学校指定の場所に置きます。
    • 外部への送信は「AIで一括読み取り」を先生が自分で開始したときだけです。それ以外は通信しません（フォントの読み込みを除く）。
    • ○×の判定・集計・評価・指導ヒントは、すべて正答表との照合で決まります。同じ答えには必ず同じ判定が出るので、採点のブレがありません。
    • AIの結果は「下書き」です。先生が確認して保存したものだけが集計され、「評価を確定」すると書き換えできなくなります（解除も可能）。

    AI読み取りを使う前に

    1. 所属の許可：自治体の教育情報セキュリティポリシーで、外部の生成AIに答案画像を送ってよいか、管理職・教育委員会に確認してください。
    2. 無料枠の扱い：Gemini API の無料枠では、送った内容が Google の製品改善に使われ、人のレビュー対象になり得ます。子どもの答案（筆跡も個人に結びつく情報です）を送るなら、有料枠（Vertex AI など）か、学校が契約する Google Workspace for Education の Gemini（学習に使われない契約）を選ぶのが安全です。
    3. 氏名を写さない：氏名欄のない用紙（出席番号だけ）にするか、塗りつぶしてください。
    4. 最後は先生の目で：特に低学年や習いたての漢字は誤読があります。黄色の「要確認」は必ず見てください。

    とめ・はね・はらいについて

    文化審議会国語分科会「常用漢字表の字体・字形に関する指針」（2016年）では、とめ・はね・はらいなどの違いは、多くの場合、字の正誤を分けるものではないとされています。AIに細部の判定を任せるより、「何を×にするか」を校内で正答表とあわせて決めておくことをおすすめします。
